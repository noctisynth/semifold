---
title: Using Semifold with agents
description: Install the Semifold skill and read task guidance from your installed CLI.
---

The Semifold skill lets an agent discover release tasks and read instructions from your installed CLI. Task guidance is available offline and stays aligned with the CLI version.

## Install the skill

Export the skill into a new directory:

```sh
smif skill export --output ./semifold
```

The command creates a directory containing `SKILL.md`. Place that directory in the skills location supported by your agent client. The parent directory must already exist.

You can also install [skills/semifold](https://github.com/noctisynth/semifold/tree/main/skills/semifold) through your client's repository skill installer, using repository `noctisynth/semifold` and path `skills/semifold`. The skill uses the [Agent Skills format](https://agentskills.io/specification).

## Use task guidance

1. Run `smif skill list` to list the available tasks.
2. Run `smif skill get <task>` to read a task's instructions.
3. Use the returned `data.commands` to find command help, then follow `data.instructions`.

For example:

```sh
smif skill get release --language en
```

Use `--language zh` for Chinese guidance. Without this option, Chinese system locales select Chinese; other locales select English. The [skill command reference](/docs/commands/skill/) describes the JSON response.

Use the same executable for guidance and execution. After upgrading or switching executables, read the task list and instructions again. The installed skill entry point can be reused across CLI upgrades that support the same discovery protocol.
