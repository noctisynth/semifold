title: 与 Agent 一起使用 Semifold

Semifold Skill 让 Agent 从已安装的 CLI 发现发布任务并读取操作指引。指引可离线使用，并与 CLI 版本保持一致。

## 安装 Skill

将 Skill 导出到一个新目录：

```sh
smif skill export --output ./semifold
```

命令会创建包含 `SKILL.md` 的目录。将该目录放到 Agent 客户端支持的技能位置即可，导出目录的父目录需要已存在。

也可以使用客户端的仓库技能安装功能，指定仓库 `noctisynth/semifold` 和路径 `skills/semifold`，安装 [Semifold Skill](https://github.com/noctisynth/semifold/tree/main/skills/semifold)。该技能采用 [Agent Skills 格式](https://agentskills.io/specification)。

## 使用任务指引

1. 运行 `smif skill list`，列出可用任务。
2. 运行 `smif skill get <task>`，读取任务指引。
3. 通过返回的 `data.commands` 查找命令帮助，再按 `data.instructions` 执行。

例如：

```sh
smif skill get release --language zh
```

使用 `--language en` 可读取英文指引。省略该选项时，中文系统 locale 使用中文，其他 locale 使用英文。JSON 响应格式见 [skill 命令参考](/zh/docs/commands/skill/)。

读取指引和执行任务使用同一个可执行文件。升级或切换可执行文件后，重新读取任务列表和指引。只要 CLI 支持相同的发现协议，已安装的 Skill 入口可以继续使用。
